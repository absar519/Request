This folder holds the site's media.

music.mp3
  A short, soft placeholder tone (a simple 4-note arpeggio) so the
  music player works immediately. Replace this file with your own
  romantic piano track — keep the filename "music.mp3" and nothing
  else needs to change.

album-art.jpg (optional)
  Not included. If you want a photo in the music player's album
  square, add an image here and set it as the background of
  ".album-art" in style.css (there's a comment there marking the spot).
